Mathematical Notes

What is it?

The Mandelbrot set is a famous fractal that reveals infinite complexity as you zoom in. It's defined as the set of complex numbers c for which the function f(z) = z² + c does not diverge when iterated from z = 0.

The Mathematics

f(z) = z² + c where z₀ = 0 zₙ₊₁ = zₙ² + c If |zₙ| remains bounded as n → ∞, then c is in the Mandelbrot set

How it Works

For each point c in the complex plane, we iterate the function starting from z = 0. If the magnitude of z ever exceeds 2, the point will escape to infinity (it's not in the set). The number of iterations before escape determines the color.

Key Features

• Main Cardioid: The large heart-shaped region
• Bulb: The circular region to the left
• Seahorse Valley: Spiral patterns
• Mini-Mandelbrots: Smaller copies of the whole set

The Burning Ship

A variation where we take the absolute value of each component before squaring: z = (|Re(z)| + i|Im(z)|)² + c. It resembles a ship on fire and has its own unique, often more "organic" looking structures.

Infinite Complexity

The boundary of the Mandelbrot set has fractal dimension 2, meaning it's infinitely detailed. No matter how much you zoom, you'll always find new patterns and structures.

Connection to Chaos Theory

The Mandelbrot set demonstrates how simple nonlinear equations can produce incredibly complex behavior - a fundamental concept in chaos theory and dynamical systems.
